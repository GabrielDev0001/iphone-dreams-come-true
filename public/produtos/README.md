# Fotos dos aparelhos

Coloque aqui a foto de cada aparelho **na cor correspondente**. O site usa a foto
automaticamente; enquanto o arquivo não existir, ele mostra a ilustração vetorial.

## Nome do arquivo

```
{id-do-modelo}-{cor-em-slug}.jpg
```

O `id-do-modelo` é o campo `id` em `src/lib/iphones.ts`. A cor é o nome da cor em
minúsculas, sem acento, com hífen no lugar do espaço.

Exemplos:

```
17-pro-max-laranja-cosmico.jpg
17-pro-max-azul-profundo.jpg
16-pro-titanio-natural.jpg
14-meia-noite.jpg
```

## Recomendações

- Fotografe o **seu** estoque, não use render de divulgação da Apple — as imagens
  oficiais são protegidas por direito autoral e o cliente precisa ver o aparelho
  que vai receber.
- Fundo neutro, aparelho centralizado, mesma distância em todas as fotos.
- Proporção quadrada (ex.: 1200×1200) e no máximo ~200 KB por arquivo, senão a
  vitrine fica lenta no celular.
- Nos semi-novos, vale uma foto por aparelho real em vez de uma por cor.
